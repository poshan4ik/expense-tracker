# Трекер расходов

Учебный проект на Python: учёт расходов с графическим интерфейсом в тёмной теме.

## Технологии

- Python 3.10+
- customtkinter — современный GUI
- sqlite3 — хранение данных
- matplotlib — круговая диаграмма

## Установка и запуск

```bash
pip install -r requirements.txt
python main.py
```

## Структура проекта

| Файл | Назначение |
|------|-----------|
| `main.py` | Точка входа (запуск) |
| `theme.py` | Цвета, шрифты, размеры |
| `database.py` | Работа с SQLite (add, get, delete) |
| `logic.py` | Расчёты и валидация ввода |
| `app.py` | Главное окно: вкладки «Расходы» и «Статистика» |

## Функционал

- Добавление расхода: сумма, категория, дата, описание
- Таблица с фильтром по категории и удалением записей
- Итоговая строка: количество и сумма
- Статистика: 3 карточки + круговая диаграмма
- Проверка ввода с окнами сообщений об ошибках
